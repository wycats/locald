# Design: UX Improvements (Phase 25)

> **Roadmap**: Polishing the workflow beyond MVP.

## Immediate UX Ideas

- **Focused failure messages**: When `locald up` fails, show the single most likely issue first, with a one-line fix.
- **Contextual help**: `locald status` should hint at next steps when idle.
- **Service naming guidance**: Warn on ambiguous or duplicate names.
- **Friendly hostnames**: Offer human-readable domains by default.

## Theme

`locald` should feel calm: the core loop is short, stable, and predictable. UX improvements should emphasize clarity and next-step guidance, not new complexity.
