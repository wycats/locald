> **Roadmap**: This is a proposal, not yet implemented.

## Goal

Upgrade the local proxy to support multi-service routing, modern protocols, and richer diagnostics without extra configuration.

## Direction

- Path-based routing under a single domain.
- HTTP/2 and HTTP/3 support.
- Structured traffic logs with failure explanations.
