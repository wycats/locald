> **Roadmap**: This is a proposal, not yet implemented.

## Goal

Support multi-project workspaces (monorepos or polyrepos) with shared configuration and “always up” services.

## Direction

- Constellations as groups of projects.
- Cascading configuration (global → context → workspace → project).
- Optional resource sharing across projects.
