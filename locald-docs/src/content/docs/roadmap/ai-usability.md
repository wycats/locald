> **Roadmap**: This is a proposal, not yet implemented.

## Goal

Make `locald` easy for AI agents to understand and operate through structured outputs.

## Direction

- `locald ai context` for a one-shot state snapshot.
- `locald ai schema` for config schema output.
- Optional `llms.txt` for concise documentation.
